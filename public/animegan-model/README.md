# AnimeGAN model (Hayao style)

Self-hosted TensorFlow.js GraphModel used by `src/lib/cartoonify.ts` for the
Photo screen's CARTOONIFY button. Runs entirely on-device (WebGL) — the
photo never leaves the browser.

- Source: https://github.com/TonyLianLong/AnimeGAN.js (`public/model_full/`)
- Underlying model: https://github.com/TachibanaYoshino/AnimeGAN

Beadable blueprint out.

Twelve screens covering the full wizard from your spec — library, board setup, photo, perlified result, manual editing, final preview, export, collection management — plus first run, board calibration, two interlocked boards, and the iPad split-panel editor. Turn 4 carries a second visual direction, Pegboard, built out to all twelve screens, plus a three-screen Darkroom sample that was set aside. Every bead grid below is really generated and really counted, so the legend numbers are honest.

ASSUMPTIONS I MADE
Single user, no accounts, so no profile or auth chrome anywhere. Default board is one 29×29 regular pegboard. Wizard is linear but every step is reachable again from the editor — you'll re-crop and re-match constantly. Source photo shown is a generated stand-in.
WHY IT LOOKS LIKE THIS
Setup and library screens sit on warm paper — this is a craft tool, not a productivity app. The editor flips to near-black so bead colors are judged against neutral, not against a tinted UI. One accent (terracotta) for actions only; every other color on screen is a bead.
